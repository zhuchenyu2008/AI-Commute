# 行程分享图信息密度修正设计

## 目标

修正分享图正文方形区域内的信息密度。保留用户已经认可的主标题、地点和路线标题字号，只放大指标区与路线次级信息，并用自适应垂直间距消除无信息的底部留白。

## 已确认范围

- 正文区域继续保持最低 `540 x 540`，底部二维码栏继续独立增加 `108px`。
- 整图最高仍为 `540 x 960`，达到 `9:16` 上限前不截断文字。
- 行程主标题、目的地文字和每段路线标题保持当前字号。
- 放大“最晚出发”“目标到达”“预计用时”三个标签及其数值。
- 放大每段路线的说明文字和右侧分钟标签。
- 路线说明使用与字号匹配的行高，避免字体变大后行距过紧。
- 路线列表占用正文剩余高度；内容较少时在路线条目之间分配剩余空间，使最后一条路线靠近正文底部，不留下大片无信息区域。
- 内容较多时保持自然内容高度，不强行拉开间距；超过最大正文高度时沿用现有上限处理。

## 布局方案

采用“保留标题 + 放大次级信息 + 弹性分配剩余高度”的组合方案。

指标标签与数值使用独立的基础字号，不再与路线标题共用同一视觉等级。路线标题继续沿用当前 `14px` 基础字号及密度缩放；路线说明和分钟标签提高基础字号，并设置显式相对行高。

正文容器保持纵向 flex 布局，路线区域使用剩余高度。路线列表仅在存在额外空间时通过 `justify-content: space-between` 分配条目间距；因此三段路线会自然铺满剩余区域，而长路线仍按内容高度正常向下扩展。

## 自适应规则

- 稀疏内容：指标和路线次级信息使用较大字号，路线条目分散填满剩余高度。
- 中等内容：字号保持可读，剩余空间只增加条目间距。
- 密集内容：沿用现有内容密度缩放，减少字号与额外间距，优先完整展示文字。
- 路线标题不因本次修正额外放大。

## 验证

- 组件测试断言路线标题字号规则未变化，指标与路线次级信息使用更大的基础字号和显式行高。
- 浏览器测试使用三段路线样例，断言最后一条路线接近正文底部，正文底部不再出现大片空白。
- 浏览器测试同时断言指标标签、指标数值、路线说明和分钟标签的实际计算字号达到新的可读性下限。
- 保留正文 `1:1`、二维码栏高度及整图 `9:16` 上限测试。
